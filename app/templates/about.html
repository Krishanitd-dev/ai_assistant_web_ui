About AI Assistant

This AI Assistant is a full-stack web application that provides AI-powered responses to programming and technology-related uestions using a Large Language Model (LLM). The application combines a FastAPI backend, interactive frontend interface, SQLite database integration, and AI API services to create a complete AI-powered web experience.

Users can submit questions, receive AI-generated answers, save and retrieve conversation history, manage stored conversations, and download AI responses as PDF documents through a clean and responsive user interface.

Project Overview

This project demonstrates:

  • Full-stack web development
  • AI API integration
  • Backend development with Python and FastAPI
  • Frontend development using HTML, CSS, and JavaScript
  • Responsive web design
  • SQLite Database integration
  • Version control using Git and GitHub
  • Deployment to the cloud
